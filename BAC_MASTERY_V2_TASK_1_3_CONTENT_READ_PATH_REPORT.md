CORE ARCHITECTURAL INVARIANTS & ENFORCEMENT\n\n### A. Non-Negotiable Semantic Distinctions\n- **Curriculum ≠ Subject ≠ Topic ≠ Skill:**  \n  `Subject` is a disciplinary field (`math`).  \n  `Topic` is an organizational chapter (`math_topic_functions`) that groups skills without being an assessable competence itself.  \n  `Skill` is an assessable learning competence (`math_asymptotes_limits`).  \n  The adapter layer strictly prohibits collapsing these distinct layers.\n- **Difficulty ≠ Cognitive Demand ≠ Practice Tier:**  \n  Integer difficulty (1, 2, or 3) measures calibrated problem complexity.  \n  A question marked `difficulty: 3` is **never** promoted to `cognitiveDemand: "analysis_synthesis"` or `practiceTier: "bac_exam_level"` unless explicitly declared by authoritative metadata.\n- **Error ≠ Misconception:**  \n  An error taxonomy code (`calculation_error`, `misunderstood_concept`) records an observational outcome.  \n  A misconception is an underlying flawed mental model. Bare error strings are rejected by `adaptLegacyMisconception`, and authentic misconception traps (e.g. from `DiagnosticOption.misconceptionDetails`) are mapped safely.\n- **No Forced MCQ Conversion:**  \n  Authentic formats authored in the platform—including accounting double-entry journals (`InteractiveJournal.tsx`) and step-by-step mathematical proof deduction (`InteractiveSteps.tsx`)—are preserved verbatim in `format: "journal_entry"` and `format: "step_by_step"`.\n- **Text Explanation ≠ Rubric:**  \n  Generic text explanations or markdown strings are **never** synthetically parsed into structured ministerial rubrics. If structured criteria (`criteria: RubricCriterion[]`) are missing, the rubric is marked `UNAVAILABLE`, and raw text is preserved in metadata.\n- **Retest Twin Safety:**  \n  Only explicit retest relationships (`retestForQuestionId`) are mapped. The adapter never synthesizes fake twin questions.\n- **Rights Safety:**  \n  If content rights are undeclared, `rightsStatus` defaults to `"unknown"` and is documented in metadata. The platform never assumes public domain or unrestricted distribution.\n\n---\n\n## 4.
