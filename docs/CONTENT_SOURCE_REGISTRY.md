## 1. Classification Framework

Every piece of educational content, curriculum structure, scoring coefficient, and pedagogical recommendation in BAC Mastery must be grounded in an authoritative source. Sources are classified into five mutually exclusive tiers:

| Tier Code | Classification Name | Definition & Evidentiary Standard |
| :--- | :--- | :--- |
| **`OFFICIAL_CURRENT`** | Current Official Source | Directly confirmed by an active official ministerial document, decree, or circular explicitly valid for the current academic cycle (BAC 2027). |
| **`OFFICIAL_HISTORICAL`** | Historical Official Source | Issued by the Algerian Ministry of National Education (MEN) or ONEC, dating from prior sessions. Validated as historical precedent; flagged as historical reference. |
| **`BAC_MASTERY_DERIVED`** | Internal Pedagogical Model | Proprietary pedagogical taxonomy, atomic skill decomposition, error diagnostics, and remediation sequences authored specifically for the BAC Mastery learning engine. |
| **`RESEARCH_SUPPORTED`** | Peer-Reviewed Cognitive Science | Rigorous scientific research published in peer-reviewed journals (cognitive load, retrieval practice, distributed practice, error metacognition, deliberate practice). |
| **`UNVERIFIED`** | Tentative / Unconfirmed | Claims lacking direct ministerial or empirical evidence for BAC 2027. Must never be presented as official policy. |
