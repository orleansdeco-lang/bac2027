## 2. Pedagogical Architecture of the 14-Element Lesson Model

Every lesson across all 31 skills strictly implements the 14 mandatory didactic elements designed for cognitive load minimization and rapid autonomous learning:

1. **Target Capability (القدرة المستهدفة)**: "بعد ما نكمل هذا الدرس، واش نقدر ندير وحدي؟" — Explicit behavioural outcome.
2. **Prerequisites & Core Requisites (ماذا يجب أن تعرف)**: Essential prior concepts needed before tackling the skill.
3. **High-Stakes Relevance (علاش هذا مهم في البكالوريا)**: Specific historical exam weight, score allocation, and recurring patterns.
4. **Core Pedagogical Concept (الفكرة الأساسية)**: Rigorous mathematical/physical/biological theorem or principle.
5. **Intuitive Elucidation (شرح بسيط ومباشر)**: Plain Arabic breakdown with key French scientific keywords.
6. **Worked Example Problem (مسألة نموذجية محلولة)**: Real exam-style problem statement.
7. **Cognitive Thinking Process (كيفاش نفكر قبل ما نكتب)**: Metacognitive internal dialogue guiding problem analysis.
8. **Execution Steps (خطوات الحل النموذجية >= 3)**: Unambiguous algebraic/methodological steps leading to the result.
9. **Final Answer Formulation (صياغة الإجابة النهائية)**: Model presentation according to ministerial marking scales.
10. **Verification Strategy (حيلة التحقق السريع)**: Reality check and dimensional validation tip.
11. **Common Misconceptions (أخطاء شائعة مع التشخيص)**: Linked directly to the Error Lab taxonomy (`suspectedErrorType`).
12. **Mastery Self-Diagnostic (كيفاش تتأكد بلي راك فاهم)**: Self-assessment checkpoint criteria.
13. **Active Recall Prompt & Answer (سؤال الاسترجاع السريع)**: Immediate retrieval testing memory trace.
14. **Autonomous Remediation Protocol (واش دير لوكان تغلط)**: Targeted fallback action plan.
