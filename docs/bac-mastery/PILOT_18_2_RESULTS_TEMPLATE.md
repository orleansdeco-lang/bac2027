## 1. Aggregation Methodology & Architectural Note
> [!IMPORTANT]
> **Data Collection Architecture**: Because telemetry and feedback are buffered **locally on student devices** (`localStorage`), results cannot be queried via automated remote SQL dashboards. The observer manually collects the anonymized JSON files generated via `/account` (`exportAnonymizedPilotData`), and aggregates the funnel metrics into this standardized document.
